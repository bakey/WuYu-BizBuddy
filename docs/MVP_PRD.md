# 无隅 BizBuddy MVP 产品需求文档

> 部署基线：本地桌面客户端 + 企业私有云服务。RAG 文档处理、索引和检索仅在企业私有云运行，不在用户电脑部署本地 RAG。

## 1. 产品定位

无隅 BizBuddy MVP 是一个**面向工业企业的桌面端对话式安全环保合规助手**，形态类似 Codex / Claude Code 这类本地 Agent 工具，以安装包形式分发给企业员工，支持 **macOS 和 Windows**。

用户面对**一个统一的对话入口**（无隅工业助手），通过自然语言提问。系统内置**一个专家 Agent：安全环保合规专家**，基于两类数据进行回答：

1. **企业知识库**：由用户从桌面端上传文档（安全制度、作业规程、排污许可证、危废管理制度、法规文件等），在企业私有云中统一解析、索引和维护的 RAG 检索库。
2. **企业时序数据**：由企业内部管理人员在管理后台统一接入的 DCS / PLC / SCADA 等实时生产数据（如环保在线监测点位）。

产品采用**桌面客户端 + 企业私有云服务**的混合形态：桌面客户端安装在用户电脑上，提供对话、文档上传和结果展示；企业私有云负责文档存储与处理、RAG 索引和检索、时序数据接入与缓存、模型配置、对话历史和执行日志。**大模型推理允许由私有云服务联网调用外部 OpenAI 兼容 API**（由管理员统一配置）。

用户**不需要在每次提问时选择文档或数据源**。文档上传到企业私有云后即被异步解析、切片、向量化并纳入企业知识库；DCS 数据由管理员在后台统一接入；提问后 Agent 自动判断是否需要检索文档和/或查询时序数据，再结合模型生成回答。

数据边界如下：

- **用户电脑**：桌面客户端、用户主动选择上传的源文件、必要的运行配置和会话展示缓存。
- **企业私有云**：上传后的文档副本、文档元数据、向量索引、对话历史、执行日志、DCS 配置与最近 7 天时序数据。
- **外部模型服务**：仅接收完成回答所必需的问题和检索上下文，不接收整库文档；所有调用由企业私有云统一发起。

MVP 阶段聚焦**安全环保合规场景**：

- **特殊作业合规**：有限空间、动火、高处作业等作业前的安全条件检查
- **环保排放监测**：排放口 SO₂、NOx、粉尘等指标的超标风险分析
- **危废与制度核查**：危废台账、安全制度、排污许可证的合规问答

所有结论的证据来自文档 + 时序数据。

## 2. 目标用户

- 安全环保工程师（EHS）
- 生产管理人员
- 车间主任 / 班组长
- 企业 IT 管理员（负责首次部署、模型配置、DCS 接入）

目标用户不是 AI 专家，也不会写 SQL，需要一个像同事一样能问、能答、能指出来源的入口。他们的电脑以 Windows 办公机为主，部分管理岗位使用 Mac。

## 3. MVP 范围

| 模块 | 功能 | 说明 |
|------|------|------|
| 桌面应用 | 安装包与自动更新 | macOS / Windows 安装包；应用内自动更新 |
| 对话 | 自然语言问答（统一入口） | 用户直接提问，安全环保合规专家自动检索知识库和后台时序数据 |
| 数据库 | 文档上传 | 从桌面端上传文档，由企业私有云自动解析、入库，作为统一 RAG 知识库 |
| 能力 | 内置一个专家 | 安全环保合规专家；对用户呈现为能力介绍页 |
| 管理后台 | 文档与索引管理 | 管理员查看/管理用户上传的文档，查看 RAG 索引状态，支持重建索引 |
| 管理后台 | DCS 数据接入管理 | 管理员配置时序数据源，查看连接状态和已接入客户端 |
| 系统 | 模型配置 | 仅管理员可见，在私有云管理后台配置 OpenAI 兼容端点 |
| 系统 | 轨迹观测 | 仅管理员可见，查看执行日志 |
| 系统 | 私有云数据管理 | 文档、向量索引、对话历史、执行日志和时序缓存统一存储在企业私有云 |

## 5. 核心用户流程

### 流程 0：首次安装与初始化

1. 企业 IT 管理员先在企业私有云完成 BizBuddy 服务部署，配置内网 HTTPS 地址和管理员账号。
2. 管理员在管理后台配置外部模型端点（Base URL、API Key、模型名），测试连接通过后设为默认模型。
3. 员工从企业内部分发渠道下载安装包（macOS `.dmg` / Windows `.exe`），按常规桌面应用方式安装。
4. 桌面客户端首次启动时进入初始化引导，配置或自动发现企业私有云服务地址，并完成连接与服务就绪检查。
5. 私有云不可达或默认模型未配置时，对话功能不可用并给出明确引导；客户端仍可浏览已缓存的历史对话。
6. 后续版本通过应用内自动更新升级，无需重新安装。

### 流程 1：文档知识库问答

1. 用户在「数据库 → 文档数据」上传文档（如《有限空间作业管理制度.pdf》）。
2. 桌面客户端将文档通过企业内网 HTTPS 上传到私有云，上传成功后显示处理状态。
3. 私有云异步完成解析、切片、Embedding 和向量入库；该过程不调用外部公共文档处理服务。
4. 状态变为「已入知识库」后，用户在对话页直接输入问题，例如：「明天 2#反应釜有限空间检修，需要检查哪些安全条件？」
5. 安全环保合规专家自动检索私有云企业知识库中的相关文档片段。
6. 生成回答并标注引用来源 `[1]`、`[2]`。

### 流程 2：知识库 + DCS 联合分析

1. 用户直接提问，例如：「最近二号线排放口 SO₂ 是否有超标风险？」
2. 专家判断该问题涉及时序数据，自动查询私有云已接入的环保监测点位。
3. 同时检索私有云企业知识库中的排污许可证限值和相关制度文件。
4. 生成综合分析，并分别标注文档引用和 DCS 数据来源。

### 流程 3：管理员接入 DCS 数据

1. 管理员从桌面端入口或企业内网地址进入「管理后台 → DCS 接入」。
2. 添加数据源：选择 MVP 已启用的 OPC UA 协议，填写连接参数并通过在线 Collector 测试连接；Modbus / MQTT 仅预留扩展能力，本期不可选。
3. 连接成功后，在「接入客户端」中可看到对应客户端上线，开始采集点位数据。
4. 普通员工在对话中无需任何配置，提问时专家自动查询已接入的数据。

**说明**：
- 文档、向量索引、对话历史、执行日志和时序数据缓存均存储在企业私有云，桌面端只保留必要缓存，不作为 RAG 数据源。
- 公网不可用但企业内网和私有云可用时，用户仍可上传和管理文档、查看管理后台；需要外部模型推理的对话不可用并给出明确提示。
- 企业内网或私有云不可用时，文档上传、RAG 问答和管理后台不可用；桌面端可浏览已缓存的历史对话并显示私有云连接异常。
- DCS 数据由管理员在管理后台统一接入和配置，普通员工不可见配置细节。

## 6. 页面详细说明

### 6.1 新对话（首页）

**入口**：打开产品默认进入。

**界面元素**：

- 顶部：当前对话标题、状态（进行中 / 已完成）。
- 中部：消息列表，区分用户消息和助手消息。
- 无消息时显示首页引导：欢迎语 + 按场景分类的示例问题卡片（特殊作业 / 环保监测 / 危废管理 / 制度核查），点击卡片直接发起提问。
- 助手消息包含：
  - 文字回答
  - 引用卡片（文档片段 / DCS 数据说明）
  - 思考过程展开（可选，默认收起）
- 底部输入区：
  - 文本输入框
  - 发送按钮
- 私有云不可达、外部模型不可达或模型未配置时，输入区上方显示明确的状态提示条。

**MVP 不做**：

- 对话中的「上传文档」按钮（文档统一在数据库页上传后进入私有云知识库）
- 对话中的「数据」选择器（DCS 由后台统一接入，Agent 自动判断）
- 技能选择器
- 模型选择器（由管理员在系统设置中配置）
- 思考深度调节器
- 审批权限选择器

### 6.2 能力页

**入口**：左侧导航「能力」。

**定位**：能力介绍页，展示系统内置的安全环保合规专家及其覆盖场景。

**内容**：

- 一个能力卡片：
  - **安全环保合规专家**：特殊作业合规、环保排放监测、危废管理、制度核查
- 卡片包含：名称、简介、能力标签、示例问题（可点击填入对话）、数据来源说明

**MVP 不做**：

- 专家搜索 / 分类筛选
- 创建专家
- 专家团

### 6.3 数据库 → 文档数据（用户侧）

**入口**：左侧导航「数据库」。

**功能**：

- 文件上传按钮（支持拖拽上传）
- 文件列表：名称、类型、状态、大小、更新时间
- 文件状态：上传中 / 解析中 / 已入知识库 / 失败
- 上传或处理失败时显示原因并支持重试
- 删除文件（删除后同步从私有云文档存储和 RAG 索引移除）

**文档生命周期**：

1. 用户上传文件
2. 桌面客户端将文件上传到企业私有云
3. 私有云异步解析、切片、Embedding、写入向量库
4. 状态变为「已入知识库」
5. 专家在回答问题时自动检索该文档

**MVP 不做**：

- 文件夹层级管理
- 版本管理
- OCR 状态展示
- 外部网盘同步
- 按文档单独选择是否参与某次问答

### 6.4 管理后台（管理员）

**入口**：左侧导航「管理后台」，仅管理员可见；点击后在默认浏览器打开企业内网管理后台。分为三个 Tab。

#### 6.4.1 文档与索引

**功能**：

- 概览卡片：文档总数、已入索引、解析中、解析失败
- 文档管理表格（含全部用户上传的文档）：
  - 列：名称、上传人、大小、解析状态、索引状态（向量条数）、上传时间、操作
  - 操作：查看详情、重建索引、删除
- 索引状态说明：
  - 每个文档显示切片数和已向量化条数（如 `128 / 128`）
  - 解析失败文档显示失败原因，支持重新解析

#### 6.4.2 DCS 接入

**功能**：

- 数据源列表表格：
  - 列：名称、协议、连接地址、点位数、状态（已连接 / 连接失败 / 已停用）、操作
  - 操作：编辑、测试连接、停用/启用、删除
- 「+ 添加数据源」按钮，弹出配置表单：
  - 名称、协议（MVP 启用 OPC UA；Modbus / MQTT 仅预留，界面不可选）
  - 连接参数（地址、端口、认证信息，按协议动态展示字段）
  - 点位配置（tag 列表：点位名、显示名、单位、说明；支持批量导入）
  - 保存前必须「测试连接」通过

#### 6.4.3 接入客户端

**功能**：

- 已接入采集客户端列表：
  - 列：客户端名称、协议、最近心跳、数据延迟、状态（在线 / 离线）
  - 客户端与数据源的关联是动态的，不在列表中展示静态绑定关系
- 用于管理员确认采集链路是否正常工作
- MVP 阶段客户端为只读视图，不提供远程操作

**MVP 不做**：

- 多租户 / 多厂区隔离
- 点位数据的图表可视化（后台只做接入管理，数据消费走对话）
- 客户端远程启停与下发配置

### 6.5 系统设置 → 模型配置（管理员）

**入口**：企业内网管理后台「模型配置」；仅管理员可进入并修改。

**功能**：

- 显示当前默认模型
- 配置一个或多个 OpenAI 兼容端点（API Key、Base URL、模型名）
- 选择默认对话模型
- 测试连接
- 查看和配置私有云数据存储路径与容量（文档、向量库、对话历史、时序数据）

**MVP 不做**：

- 多模型路由策略
- 模型用量统计
- 本地 LLM 推理（仅支持云端 API）

### 6.6 轨迹观测（管理员）

**入口**：企业内网管理后台左侧导航「轨迹观测」。

**功能**：

- 执行记录列表：时间、问题、状态、引用数、耗时
- 点击展开：计划步骤、工具调用、引用来源、Token 消耗

**MVP 不做**：

- 费用统计
- 成功率趋势
- 失败自动归因

## 7. 系统模块需求

| 模块 | 说明 |
|------|------|
| 桌面应用壳 | 新增：macOS / Windows 安装包、自动更新、首次启动引导、私有云地址配置与连接状态检测 |
| 内置专家 | 调整：仅保留安全环保合规专家（composite agent） |
| AgentExecutor | 调整：根据问题自动判断是否需要查询时序数据；context 支持传入 document chunks 和 time-series summary |
| 私有云服务 | 新增：统一承载客户端 API、管理员鉴权、文档上传、RAG、DCS 数据接入、模型配置和执行日志 |
| 文档解析服务 | 复用现有：支持 PDF / Word / Excel / 图片，部署在企业私有云运行 |
| RAG 索引管理 | 新增：向管理后台暴露索引状态（切片数、向量化进度、失败原因），支持按文档重建索引 |
| RAG 检索 | 复用现有：基于文档向量检索，元数据和向量统一存储在企业私有云 PostgreSQL + pgvector |
| 时序数据接入服务 | 新增（管理后台用）：MVP 启用 OPC UA，架构预留 Modbus / MQTT；接入一条产线的环保监测点位，在企业私有云保留最近 7 天数据；仅管理员可配置 |
| 采集客户端管理 | 新增：上报客户端心跳与数据延迟，供管理后台展示 |
| 执行日志 | 复用现有：在企业私有云记录每次执行的计划、步骤、引用、耗时 |

> 具体的数据模型与 API 设计不在本 PRD 范围内，见技术设计文档 `docs/MVP_Client_Tech_Design.md`。

## 8. 非功能需求

| 项 | 要求 |
|----|------|
| 支持平台 | macOS 12+（Apple Silicon / Intel）；Windows 10 / 11（64 位） |
| 安装与更新 | 标准安装包（dmg / exe）；应用内自动更新；支持企业内网分发 |
| 并发 | 桌面客户端按单用户使用；私有云按单企业部署并服务企业内部用户；管理后台仅管理员使用 |
| 响应时间 | 简单文档问答 < 10s；涉及时序数据 < 20s |
| 资源占用 | 空闲内存占用 ≤ 2GB；安装包体积 ≤ 500MB |
| 数据保留 | 文档、向量索引和对话历史长期保留在企业私有云；DCS 数据在私有云保留 7 天；桌面缓存可清理 |
| 离线行为 | 公网不可用但私有云可达时可上传/管理文档；模型问答不可用。私有云不可达时仅可浏览桌面已缓存的历史对话，并明确提示连接异常 |
| 安全 | 私有云数据加密存储；模型 API Key 使用服务端密钥管理能力加密保存；桌面缓存使用操作系统级安全存储；管理后台仅管理员可见；客户端、私有云和外部模型之间均通过 HTTPS |
| 兼容性 | 双平台 UI 一致性；高分屏适配；系统亮/暗色主题跟随 |

| 指标 | 目标 |
|------|------|
| 桌面应用在 macOS / Windows 安装成功 | 内部测试设备 100% |
| 从下载安装包到完成首次问答 | ≤ 30 分钟（含管理员模型配置） |

| 用户能完成一次安全制度/作业规程的文档问答 | 100% 可用 |
